# 🚀 MiVPS Script Manager

Panel de administración privado y ligero para servidores VPS con Ubuntu/Debian.

## 📦 Instalación
Copia y pega este comando en tu terminal como usuario **root**:

```bash
wget -qO install.sh https://raw.githubusercontent.com/jorge415nivel/MiVPS/main/install.sh && chmod +x install.sh && ./install.sh
